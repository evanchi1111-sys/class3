# 🎒 清水國小五年丙班｜丙肩作戰！

清水國小五年丙班的班級網站：公告、行事曆、當日作業（聯絡簿）、校外活動與親師溝通資訊集中在同一頁，家長與同學用手機就能查看。

**網站**：<https://evanchi1111-sys.github.io/class3/>

## 內容

| 區塊 | 說明 |
|---|---|
| 快速連結 | 常用的校內與學習網站 |
| 最新公告 | 班級公告，依日期排列 |
| 本週行事曆 | 本週小考、活動與需攜帶物品 |
| 校外活動資訊 | 活動名稱、集合時間、攜帶物品、安全提醒 |
| 班級基本資料 | 班級介紹 |
| 當日作業（聯絡簿） | 各科作業與其他提醒，另保留過往紀錄 |
| 親師溝通 | 聯繫方式與家長小提醒 |

## 更新方式

公告、行事曆、作業、校外活動的內容存在一份**已發佈到網路的 Google 試算表**，老師只要改試算表，網頁重新整理就會更新，不需要改程式。

| 工作表 | 欄位 |
|---|---|
| 公告 | 日期、標題、內容 |
| 行事曆 | 日期、活動、類型 |
| 作業 | 日期、國語、數學、其他提醒 |
| 校外活動 | 活動名稱、集合時間、攜帶物品、安全提醒 |

> 試算表讀取失敗或還沒有資料時，網頁會顯示預設內容。
> 試算表為「發佈到網路」的唯讀版本，**請勿填入學生個資**（姓名以外的聯絡方式、照片等）。
